# Pitch Capital

AI-powered fundraising platform. Create investor-ready pitch decks in 90 seconds, match with verified VCs, and close deals securely.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Pages

- `/` - Homepage with hero, features, how it works, testimonials
- `/features` - Detailed platform feature breakdown
- `/pricing` - Tiered pricing plans
- `/about` - Company story, team, and values
- `/faq` - Frequently asked questions
- `/contact` - Contact form and info

## Tech Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS
